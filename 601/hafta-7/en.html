The lecture opened with a three-board summary of last week. Board 1712329

Function of an operator and the continuous basis

This board is locked for now. To open it, first finish the questions of this board: .

In one sentenceTo find a function of an operator, write it in its eigenbasis and apply the function only to the eigenvalues: \(f(\hat A)=\sum_n f(a_n)\,\hat P_n\). The same three rules hold in the position and momentum bases, except that the sum becomes an integral and the Kronecker delta a Dirac delta.

The lecture opened with the heading “Previous week”; last week was summarized on three boards. The first item is functions of operators. The spectral decomposition of a Hermitian \(\hat A\):

\[ \hat A=\sum_n a_n\,\hat P_n,\qquad \hat P_n=|a_n\rangle\langle a_n| \]
\[ \begin{aligned}&\hat A = \sum_n a_n\,\hat P_n, \\[2pt] &\hat P_n = |a_n\rangle\langle a_n|\end{aligned} \]

\(\hat P_n\) is the projection operator: it separates the part of a state along \(|a_n\rangle\) and throws away the rest. In this form \(\hat A\) is a diagonal table in its own eigenbasis. Every operation is easy with a diagonal table, because projections do not “see” each other: \(\hat P_n\hat P_m=\delta_{nm}\hat P_n\). When you square it the cross terms vanish, and each eigenvalue stays with its own projection:

\[ \hat A^2=\sum_n a_n^2\,\hat P_n,\qquad \hat A^k=\sum_n a_n^k\,\hat P_n\qquad\Longrightarrow\qquad f(\hat A)=\sum_n f(a_n)\,\hat P_n \]
\[ \begin{aligned}&\hat A^2 = \sum_n a_n^2\,\hat P_n, \\[2pt] &\hat A^k = \sum_n a_n^k\,\hat P_n \\[2pt] &\quad \Longrightarrow f(\hat A) = \sum_n f(a_n)\,\hat P_n\end{aligned} \]

The last step: apply the Taylor series of f power by power; each power has the same \(\hat P_n\), and adding up applies f to the eigenvalues. The example on the board is the exponential function:

\[ e^{\hat A}=\sum_n e^{a_n}\,\hat P_n \]

This line is the key of this week. All the transformations in Chapter 8 have the form \(e^{-i\varepsilon\hat G/\hbar}\), and the unitarity proof on Board 5 is done with exactly this formula.

The second item is the continuous basis: position and momentum. The table on the board puts three properties side by side:

PropertyPosition \(\{|x\rangle\}\)Momentum \(\{|p\rangle\}\)Counterpart in a discrete basis
Eigenvalue problem\(\hat x|x\rangle=x|x\rangle\)\(\hat p|p\rangle=p|p\rangle\)\(\hat A|a_n\rangle=a_n|a_n\rangle\)
Delta normalization\(\langle x'|x\rangle=\delta(x'-x)\)\(\langle p'|p\rangle=\delta(p'-p)\)\(\langle a_m|a_n\rangle=\delta_{mn}\)
Completeness\(\hat I=\int dx\,|x\rangle\langle x|\)\(\hat I=\int dp\,|p\rangle\langle p|\)\(\hat I=\sum_n|a_n\rangle\langle a_n|\)

I added the last column; the only difference between a continuous and a discrete basis is that the labels are continuous. Every real x is a label, so the sum becomes an integral and \(\delta_{mn}\) becomes \(\delta(x'-x)\). Delta normalization has a price: \(\langle x|x\rangle=\delta(0)\) is infinite, so \(|x\rangle\) is not a normalizable state but an ideal limit. We saw this in week 4, where \(|x\rangle\langle x|\) was not a projection operator.

The red notes are unit analysis. The identity operator is unitless, \([\hat I]=1\). The unit of \(dx\) is length (L). The two sides of the completeness relation must have the same unit, and so must the ket and the bra:

\[ [\hat I]=[dx]\,\big[|x\rangle\big]\,\big[\langle x|\big]\quad\Longrightarrow\quad 1=L\cdot\big[|x\rangle\big]^2\quad\Longrightarrow\quad \big[|x\rangle\big]=\big[\langle x|\big]=L^{-1/2} \]
\[ \begin{aligned}&[\hat I] = [dx]\,\big[|x\rangle\big]\,\big[\langle x|\big] \\[2pt] &\quad \Longrightarrow 1 = L\cdot\big[|x\rangle\big]^2 \\[2pt] &\quad \Longrightarrow \big[|x\rangle\big] = \big[\langle x|\big] = L^{-1/2}\end{aligned} \]

The delta function says the same thing. Since \(\int\delta(x)\,dx=1\) is unitless, \([\delta(x)]=L^{-1}\), and \(\langle x'|x\rangle=\delta(x'-x)\) is the product of two \(L^{-1/2}\). The same calculation in the momentum basis gives \(\big[|p\rangle\big]=[p]^{-1/2}\). A unit check is the cheapest way to catch sign and factor errors in the exam; we will use it several times this week.

High school example

Finding \(3^{10}\) on a calculator is easy, but taking the tenth power of a matrix by hand is tedious. If the matrix is diagonal the job is easy again: \(\begin{pmatrix}2&0\\0&3\end{pmatrix}^{10}=\begin{pmatrix}2^{10}&0\\0&3^{10}\end{pmatrix}\). The spectral decomposition is the way to bring any Hermitian operator to this diagonal form. Then you apply whichever function you like (square, exponential, square root) to the numbers on the diagonal one by one.

Board 2

The wave function is a component, Fourier is a change of basis

This board is locked for now. To open it, first finish the questions of this board: .

In one sentence\(\psi(x)=\langle x|\psi\rangle\) and \(\phi(p)=\langle p|\psi\rangle\) are the components of the same state in two different bases; going from one to the other is a Fourier transform done with \(\langle x|p\rangle=e^{ipx/\hbar}/\sqrt{2\pi\hbar}\).

The table continues on the blackboard. The wave function is the component of a state in the position basis; the momentum wave function is its component in the momentum basis:

\[ \psi(x)=\langle x|\psi\rangle,\qquad \phi(p)=\langle p|\psi\rangle \]
\[ \begin{aligned}&\psi(x) = \langle x|\psi\rangle, \\[2pt] &\phi(p) = \langle p|\psi\rangle\end{aligned} \]

The state expansion is just putting the completeness relation in front of \(|\psi\rangle\). Do not memorize it; produce it in one line each time:

\[ |\psi\rangle=\hat I|\psi\rangle=\int dx\,|x\rangle\langle x|\psi\rangle=\int dx\,\psi(x)\,|x\rangle,\qquad |\psi\rangle=\int dp\,\phi(p)\,|p\rangle \]
\[ \begin{aligned}&|\psi\rangle = \hat I|\psi\rangle = \int dx\,|x\rangle\langle x|\psi\rangle \\[2pt] &\quad = \int dx\,\psi(x)\,|x\rangle, \\[2pt] &|\psi\rangle = \int dp\,\phi(p)\,|p\rangle\end{aligned} \]

Then the action of operators in the two representations. The rule is simple: each operator only multiplies in its own basis and becomes a derivative in the other.

The position representationThe momentum representation
\(\hat x\)\(\langle x|\hat x|\psi\rangle=x\,\psi(x)\)\(\langle p|\hat x|\psi\rangle=i\hbar\,\dfrac{\partial\phi}{\partial p}\)
\(\hat p\)\(\langle x|\hat p|\psi\rangle=-i\hbar\,\dfrac{\partial\psi}{\partial x}\)\(\langle p|\hat p|\psi\rangle=p\,\phi(p)\)

Watch the signs: in position \(\hat p\to-i\hbar\,\partial_x\), in momentum \(\hat x\to+i\hbar\,\partial_p\). The signs are opposite so that both satisfy \([\hat x,\hat p]=i\hbar\) (this relation takes the lead on Boards 12–13). A check with a test function in the momentum representation:

\[ [\hat x,\hat p]\,\phi=i\hbar\,\partial_p\big(p\,\phi\big)-p\,i\hbar\,\partial_p\phi=i\hbar\,\phi+i\hbar\,p\,\phi'-i\hbar\,p\,\phi'=i\hbar\,\phi \]
\[ \begin{aligned}&[\hat x,\hat p]\,\phi = i\hbar\,\partial_p\big(p\,\phi\big)-p\,i\hbar\,\partial_p\phi \\[2pt] &\quad = i\hbar\,\phi+i\hbar\,p\,\phi'-i\hbar\,p\,\phi' = i\hbar\,\phi\end{aligned} \]

Units. The red note at the top of the board: the state vector is unitless, \(\big[|\psi\rangle\big]=1\), because \(\langle\psi|\psi\rangle=1\). Then the unit of \(\psi(x)=\langle x|\psi\rangle\) is that of \(\langle x|\), \(L^{-1/2}\). The physical meaning fits too: \(|\psi(x)|^2\,dx\) is a probability and must be unitless. The same logic for momentum gives \([\phi(p)]=[p]^{-1/2}\).

The box at the bottom is the object linking the two bases: the wave function of a momentum eigenstate in the position basis.

\[ \langle x|p\rangle=\frac{e^{ipx/\hbar}}{\sqrt{2\pi\hbar}} \]

This is a plane wave: its amplitude is the same everywhere and its phase rotates smoothly with x. The \(1/\sqrt{2\pi\hbar}\) in front comes from delta normalization (delta-normalized):

\[ \langle p'|p\rangle=\int dx\,\langle p'|x\rangle\langle x|p\rangle=\frac{1}{2\pi\hbar}\int dx\,e^{i(p-p')x/\hbar}=\delta(p'-p) \]
\[ \begin{aligned}&\langle p'|p\rangle \\[2pt] &\quad = \int dx\,\langle p'|x\rangle\langle x|p\rangle \\[2pt] &\quad = \frac{1}{2\pi\hbar}\int dx\,e^{i(p-p')x/\hbar} \\[2pt] &\quad = \delta(p'-p)\end{aligned} \]

Once you know this, the Fourier transform comes by itself. Insert a 1:

\[ \phi(p)=\langle p|\psi\rangle=\int dx\,\langle p|x\rangle\langle x|\psi\rangle=\frac{1}{\sqrt{2\pi\hbar}}\int dx\;e^{-ipx/\hbar}\,\psi(x) \]
\[ \begin{aligned}&\phi(p) = \langle p|\psi\rangle \\[2pt] &\quad = \int dx\,\langle p|x\rangle\langle x|\psi\rangle \\[2pt] &\quad = \frac{1}{\sqrt{2\pi\hbar}}\int dx\;e^{-ipx/\hbar}\,\psi(x)\end{aligned} \]
\[ \psi(x)=\langle x|\psi\rangle=\int dp\,\langle x|p\rangle\langle p|\psi\rangle=\frac{1}{\sqrt{2\pi\hbar}}\int dp\;e^{ipx/\hbar}\,\phi(p) \]
\[ \begin{aligned}&\psi(x) = \langle x|\psi\rangle \\[2pt] &\quad = \int dp\,\langle x|p\rangle\langle p|\psi\rangle \\[2pt] &\quad = \frac{1}{\sqrt{2\pi\hbar}}\int dp\;e^{ipx/\hbar}\,\phi(p)\end{aligned} \]

The minus sign in the first line comes from \(\langle p|x\rangle=\langle x|p\rangle^*\). You do not need to memorize the Fourier transform: “insert completeness and write \(\langle x|p\rangle\)” gives both directions in two lines. You can see a narrow packet giving a wide momentum distribution by sliding the plot on Board 14 of week 6.

Board note

In the inverse Fourier transform on the board the integrand again says \(\psi(x)\): \(\psi(x)=\frac{1}{\sqrt{2\pi\hbar}}\int dp\,e^{ipx/\hbar}\,\psi(x)\). The correct form is \(\phi(p)\). The integral is over p, so the momentum wave function, which depends on p, must be inside. In the wrong form \(\psi(x)\) comes out of the integral and a meaningless \(\int dp\,e^{ipx/\hbar}\) remains. Write the correct form in the exam.

High school example

You can store a song in two ways: sound pressure in time (the waveform) or how much of each frequency there is (the equalizer bars). Both are the same song, and one is computed from the other with a Fourier transform. ψ(x) is like the waveform, “how much where”, and φ(p) is like the equalizer, “how much of which momentum”. A short “click” contains all frequencies at once; a narrow ψ likewise means a wide φ.

Board 3712329

The kernel is a table; momentum generates the shift

This board is locked for now. To open it, first finish the questions of this board: .

In one sentenceThe elements of an operator in the position basis, \(A(x',x)=\langle x'|\hat A|x\rangle\), are a continuous table; its action on a wave function is an integral taken with this table. Comparing the small form of translation \(\hat I-\frac{ia}{\hbar}\hat p\) with the Taylor expansion \(\psi(x)-a\,\psi'(x)\) gives \(\hat p=-i\hbar\,\partial_x\).

The third item is operator kernels. In a discrete basis an operator is given by the table \(A_{mn}=\langle a_m|\hat A|a_n\rangle\). In the position basis the indices are continuous, and the table becomes a function of two variables:

\[ A(x',x)=\langle x'|\hat A|x\rangle \]

To find its action on a wave function, make the move at the red arrow: put \(\hat I=\int dx'\,|x'\rangle\langle x'|\) between \(\hat A\) and \(|\psi\rangle\).

\[ (\hat A\psi)(x)=\langle x|\hat A|\psi\rangle=\int dx'\,\langle x|\hat A|x'\rangle\,\langle x'|\psi\rangle=\int dx'\,A(x,x')\,\psi(x') \]
\[ \begin{aligned}&(\hat A\psi)(x) = \langle x|\hat A|\psi\rangle \\[2pt] &\quad = \int dx'\,\langle x|\hat A|x'\rangle\,\langle x'|\psi\rangle \\[2pt] &\quad = \int dx'\,A(x,x')\,\psi(x')\end{aligned} \]

This is the continuous version of matrix multiplication: \(\int dx'\,A(x,x')\,\psi(x')\) in place of \((A\psi)_m=\sum_nA_{mn}\psi_n\). The value of the output at x is a weighted sum of the values of the input at all points x', with weights given by the kernel.

The example on the board is a local potential. The potential energy operator multiplies the wave function by the value of V at that point, \((\hat V\psi)(x)=V(x)\,\psi(x)\); it does not look at other points. So its kernel is diagonal, with a delta:

\[ V(x',x)=V(x)\,\delta(x-x')\quad\Longrightarrow\quad\int dx'\,V(x)\,\delta(x-x')\,\psi(x')=V(x)\,\psi(x) \]
\[ \begin{aligned}&V(x',x) = V(x)\,\delta(x-x') \\[2pt] &\quad \Longrightarrow \int dx'\,V(x)\,\delta(x-x')\,\psi(x') \\[2pt] &\quad = V(x)\,\psi(x)\end{aligned} \]

The note “since local” says this: for \(x\neq x'\) the kernel is zero. The difference from a nonlocal potential is on Board 11 of week 6.

The fourth item is the translation operator and its generator, momentum. The definition: shift the graph to the right, in the +x direction, by a.

\[ \big(\hat T(a)\psi\big)(x)=\psi(x-a) \]

The value of the new graph at x is the value of the old one at x − a; that is why there is a minus sign. A packet with its peak at \(x_0\) has its peak at \(x_0+a\) after the shift. The Taylor expansion for small a:

\[ \psi(x-a)=\psi(x)-a\,\frac{d\psi}{dx}+O(a^2) \]
\[ \begin{aligned}&\psi(x-a) \\[2pt] &\quad = \psi(x)-a\,\frac{d\psi}{dx}+O(a^2)\end{aligned} \]

This is the second line on the board; \(O(a^2)\) is not written but is meant. On the other hand, if translation is written in the form \(e^{-ia\hat p/\hbar}\), then for small a \(\hat T(a)\approx\hat I-\frac{ia}{\hbar}\hat p\), and applied to ψ it gives \(\psi-\frac{ia}{\hbar}\hat p\,\psi\). Equate the coefficients of a in the two expressions:

\[ -\frac{d\psi}{dx}=-\frac{i}{\hbar}\,\hat p\,\psi\quad\Longrightarrow\quad\hat p=\frac{\hbar}{i}\frac{\partial}{\partial x}=-i\hbar\,\frac{\partial}{\partial x} \]
\[ \begin{aligned}&-\frac{d\psi}{dx} = -\frac{i}{\hbar}\,\hat p\,\psi \\[2pt] &\quad \Longrightarrow \hat p = \frac{\hbar}{i}\frac{\partial}{\partial x} = -i\hbar\,\frac{\partial}{\partial x}\end{aligned} \]

The two arrows on the board are the two directions of this logic: if the exponential pattern and the Taylor expansion say the same thing, the operator generating the translation is the derivative, that is, momentum. Momentum is the generator of translation. This sentence is the bridge to Chapter 8; we will generalize the same pattern to all continuous transformations.

Does it hold for finite a too? Yes. \(e^{-ia\hat p/\hbar}=e^{-a\,d/dx}=\sum_k\frac{1}{k!}\big(-a\frac{d}{dx}\big)^k\), and this is exactly the Taylor series of \(\psi(x-a)\) around x. You can see how the tangent approximation breaks down as a grows in the plot on Board 17 of week 6.

High school example

You are on a hill with a slope of 0.2. If you take a step back of one meter your height falls by about 0.2 m: \(h(x-1)\approx h(x)-1\cdot h'(x)\). The slope, the derivative, tells you the effect of a short shift. The translation operator does this at every point of the wave function at once; in quantum mechanics that derivative, with \(-i\hbar\) added in front, is momentum.

Board 4

Every continuous transformation has a generator

This board is locked for now. To open it, first finish the questions of this board: .

In one sentenceA continuous family of transformations is written with a single operator, \(\hat U(\varepsilon)=e^{-i\varepsilon\hat G/\hbar}\). At small ε, \(\hat U\approx\hat I-\frac{i\varepsilon}{\hbar}\hat G\); this first order term, the generator \(\hat G\), tells what the transformation does.

The summary is over, and a new chapter begins: 8. Continuous Symmetries and Their Generators. The word “continuous” matters. The transformation depends on a parameter ε, and ε can be chosen as small as you like: the shift a, the rotation angle θ, the elapsed time t. A mirror reflection is not continuous; you either reflect or you do not, and there is no such thing as “reflecting a little”.

8.1 The general form. The first sentence of the board, with the word “unitary” in the red box:

\[ \hat U(\varepsilon)=e^{-\frac{i}{\hbar}\varepsilon\hat G} \]

\(\hat G\) is called the generator of the transformation. Why exponential? We expect three things from such a family:

  1. Doing nothing is the identity operator: \(\hat U(0)=\hat I\).
  2. In two successive transformations the parameters add: \(\hat U(\varepsilon_1)\,\hat U(\varepsilon_2)=\hat U(\varepsilon_1+\varepsilon_2)\). Shifting by 1 cm twice means shifting by 2 cm once.
  3. Probabilities are preserved: \(\hat U^\dagger\hat U=\hat I\).

The function satisfying the first two for numbers is the exponential: \(e^{c\varepsilon_1}e^{c\varepsilon_2}=e^{c(\varepsilon_1+\varepsilon_2)}\). For an operator, \(-i\hat G/\hbar\) takes the place of c. The third is the topic of Board 5.

If ε ≪ 1, the first two terms of the exponential series are enough:

\[ \hat U(\varepsilon)=\hat I-\frac{i}{\hbar}\,\varepsilon\,\hat G+O(\varepsilon^2) \]

The meaning of the word “generator” is in this line. A small transformation differs from the identity operator by a piece proportional to \(\hat G\); \(\hat G\) gives the direction of the transformation. A large transformation is small steps piled up:

\[ \hat U(\varepsilon)=\Big[\hat U\big(\tfrac{\varepsilon}{N}\big)\Big]^N\approx\Big(\hat I-\frac{i\varepsilon}{N\hbar}\,\hat G\Big)^N\;\xrightarrow{\;N\to\infty\;}\;e^{-i\varepsilon\hat G/\hbar} \]
\[ \begin{aligned}&\hat U(\varepsilon) = \Big[\hat U\big(\tfrac{\varepsilon}{N}\big)\Big]^N \\[2pt] &\quad \approx \Big(\hat I-\frac{i\varepsilon}{N\hbar}\,\hat G\Big)^N\;\xrightarrow{\;N\to\infty\;}\;e^{-i\varepsilon\hat G/\hbar}\end{aligned} \]

This is the operator version of the limit \((1+x/N)^N\to e^x\). \(\hat G\) says what a small step does, and the large step is “generated” from it. The translation on Board 3 is the first example of this pattern: ε = a, \(\hat G=\hat p\).

There are two details in this pattern that can get mixed up in the exam.

Why is ħ there? Nothing with a unit can go inside an exponential; the series \(1+X+X^2/2+\dots\) would be trying to add different units. The unit of \(\varepsilon\hat G\) is always that of ħ, J·s. For translation \([a\,p]=\mathrm{m}\cdot\mathrm{kg\,m/s}=\mathrm{J\,s}\). Dividing gives a unitless number.

Why is i there? If \(\hat G\) is Hermitian, \(-i\hat G\) is anti-Hermitian, and this is exactly what makes its exponential unitary. Think with numbers: if g is real, \(|e^{-ig}|=1\), but \(|e^{-g}|\neq1\). Without the i, \(e^{-\varepsilon\hat G/\hbar}\) would amplify some components and damp others; it would not preserve length. The starred sentence at the bottom of the board states this link, and the two words in the red box, unitary and Hermitian, are its two ends: \(\hat G\) must be Hermitian for \(\hat U\) to be unitary.

High school example

Velocity and position: \(x(t+\Delta t)\approx x(t)+v\,\Delta t\). Velocity tells how much the position changes in a short time; you find the long path by adding up these short steps. The generator plays the same role. Compound interest shows the same limit: if you split 100% annual interest into N parts and compound at each part, the money grows by a factor of \((1+1/N)^N\). At N = 12 it is 2.61, at N = 365 it is 2.71, and as N grows it tends to e ≈ 2.718.

Explain in your own words, then open and compare: why the exponential function?

Because in two successive transformations the parameters add, \(\hat U(\varepsilon_1)\hat U(\varepsilon_2)=\hat U(\varepsilon_1+\varepsilon_2)\), and the function that turns a product into a sum is the exponential. At small ε the exponential reduces to \(\hat I-\frac{i\varepsilon}{\hbar}\hat G\); that first order piece is the “speed” of the transformation, the generator.

The generator is Hermitian so that the transformation is unitary

This board is locked for now. To open it, first finish the questions of this board: .

In one sentenceExpanding \(\hat U^\dagger\hat U=\hat I\) to first order leaves \(\frac{i\varepsilon}{\hbar}\big(\hat G^\dagger-\hat G\big)=0\): if the transformation is unitary, the generator is Hermitian. The converse is also true: a Hermitian \(\hat G\) produces a unitary \(\hat U\) for every ε.

We prove the starred sentence at the bottom of Board 4. There are two directions and the board writes both.

Finite form: Hermitian ⇒ unitary. First the adjoint of \(\hat U\). The adjoint of an exponential is the exponential of the adjoint of the exponent, and i turns into −i:

\[ \hat U(\varepsilon)=e^{-\frac{i}{\hbar}\varepsilon\hat G}\quad\Longrightarrow\quad\hat U^\dagger(\varepsilon)=e^{+\frac{i}{\hbar}\varepsilon\hat G^\dagger} \]
\[ \begin{aligned}&\hat U(\varepsilon) = e^{-\frac{i}{\hbar}\varepsilon\hat G} \\[2pt] &\quad \Longrightarrow \hat U^\dagger(\varepsilon) = e^{+\frac{i}{\hbar}\varepsilon\hat G^\dagger}\end{aligned} \]

Now let \(\hat G^\dagger=\hat G\) and use the formula of Board 1. \(\hat G=\sum_ng_n\hat P_n\), with the eigenvalues \(g_n\) real:

\[ \hat U^\dagger\hat U=e^{+\frac{i}{\hbar}\varepsilon\hat G}\,e^{-\frac{i}{\hbar}\varepsilon\hat G}=\sum_n e^{+ig_n\varepsilon/\hbar}\,e^{-ig_n\varepsilon/\hbar}\,\hat P_n=\sum_n\hat P_n=\hat I \]
\[ \begin{aligned}&\hat U^\dagger\hat U = e^{+\frac{i}{\hbar}\varepsilon\hat G}\,e^{-\frac{i}{\hbar}\varepsilon\hat G} \\[2pt] &\quad = \sum_n e^{+ig_n\varepsilon/\hbar}\,e^{-ig_n\varepsilon/\hbar}\,\hat P_n = \sum_n\hat P_n = \hat I\end{aligned} \]

At each eigenvalue the two phases cancel, because \(g_n\) is real; this is the “if \(\hat G^\dagger=\hat G\)” and “by spectral decomposition easily follows” in the red circle. One subtlety: combining two exponentials as \(e^{\hat A}e^{\hat B}=e^{\hat A+\hat B}\) is valid only if \(\hat A\) and \(\hat B\) commute. Here the exponents are \(\hat G^\dagger\) and \(\hat G\); in the Hermitian case they are the same operator, so there is no problem. The calculation with the spectral decomposition never runs into this subtlety.

Infinitesimal form: unitary ⇒ Hermitian. Now go the other way. Let \(\hat U\) be unitary; what do we learn about \(\hat G\)? Write it to first order and multiply:

\[ \hat U^\dagger\hat U=\Big(\hat I+\frac{i}{\hbar}\varepsilon\hat G^\dagger+O(\varepsilon^2)\Big)\Big(\hat I-\frac{i}{\hbar}\varepsilon\hat G+O(\varepsilon^2)\Big)=\hat I-\frac{i}{\hbar}\varepsilon\hat G+\frac{i}{\hbar}\varepsilon\hat G^\dagger+O(\varepsilon^2) \]
\[ \begin{aligned}&\hat U^\dagger\hat U \\[2pt] &\quad = \Big(\hat I+\frac{i}{\hbar}\varepsilon\hat G^\dagger+O(\varepsilon^2)\Big)\Big(\hat I-\frac{i}{\hbar}\varepsilon\hat G+O(\varepsilon^2)\Big) \\[2pt] &\quad = \hat I-\frac{i}{\hbar}\varepsilon\hat G+\frac{i}{\hbar}\varepsilon\hat G^\dagger+O(\varepsilon^2)\end{aligned} \]

The cross term \(\frac{\varepsilon^2}{\hbar^2}\hat G^\dagger\hat G\) is second order and went into \(O(\varepsilon^2)\). Unitarity wants this to be \(\hat I\); the \(\hat I\) on the two sides cancels:

\[ 0=\frac{i}{\hbar}\,\varepsilon\,\big(\hat G^\dagger-\hat G\big)\quad\Longrightarrow\quad\hat G^\dagger=\hat G \]
\[ \begin{aligned}&0 = \frac{i}{\hbar}\,\varepsilon\,\big(\hat G^\dagger-\hat G\big) \\[2pt] &\quad \Longrightarrow \hat G^\dagger = \hat G\end{aligned} \]

ε is small but not zero, so the parenthesis must vanish. Careful: if, when writing \(\hat U^\dagger\), you had made \(\hat G^\dagger\) into \(\hat G\) from the start, you would have assumed what you wanted to prove. That is why \(\hat G^\dagger\) is deliberately written separately on the board.

The meaning of the result: the generator is Hermitian, that is, an observable. It has real eigenvalues and can be measured. The main idea of this week sprouts here: behind every continuous transformation stands a measurable quantity. Behind translation is momentum, behind rotation angular momentum, and behind time energy (Board 6).

One detail: the first order approximation is not exactly unitary. \(\big(\hat I+\frac{i\varepsilon}{\hbar}\hat G\big)\big(\hat I-\frac{i\varepsilon}{\hbar}\hat G\big)=\hat I+\frac{\varepsilon^2}{\hbar^2}\hat G^2\); the error is of order ε². As N grows the total error goes to zero and the true, length-preserving rotation appears.

High school example

Someone trying to walk on a circle takes each step perpendicular to the radius, in the tangent direction. If the steps are large, each one goes a little outside the circle and the distance from the center grows step by step. With smaller and more numerous steps the track hugs the circle. Rotation. In translation x shifted; in a rotation about the z axis the polar angle φ shifts. A small rotation δθ advances the wave function in the angular direction, \(\psi(r,\varphi)\to\psi(r,\varphi-\delta\theta)\approx\psi-\delta\theta\,\partial_\varphi\psi\). Comparing with the exponential pattern is the same calculation as on Board 3:

\[ \hat L_z=-i\hbar\,\frac{\partial}{\partial\varphi}=\hat x\,\hat p_y-\hat y\,\hat p_x \]

This derivation is not on the board; the generator was only given by name. The last equality comes from the chain rule (\(\partial_\varphi=x\,\partial_y-y\,\partial_x\)) and is the z component of the classical \(\vec L=\vec r\times\vec p\). It is exactly parallel to momentum: φ in place of x and \(\hat L_z\) in place of \(\hat p\). The positive direction of rotation follows the right-hand rule: the way your fingers curl when your thumb points along +z.

Translation in time. \(\hat U(t)=e^{-it\hat H/\hbar}\), the time evolution operator. For small δt, \(|\psi(t+\delta t)\rangle\approx\big(\hat I-\frac{i\,\delta t}{\hbar}\hat H\big)|\psi(t)\rangle\). Expand the left side with Taylor and equate the coefficients of δt:

\[ \frac{\partial}{\partial t}|\psi\rangle=-\frac{i}{\hbar}\,\hat H|\psi\rangle\quad\Longrightarrow\quad i\hbar\,\frac{\partial}{\partial t}|\psi\rangle=\hat H|\psi\rangle \]
\[ \begin{aligned}&\frac{\partial}{\partial t}|\psi\rangle = -\frac{i}{\hbar}\,\hat H|\psi\rangle \\[2pt] &\quad \Longrightarrow i\hbar\,\frac{\partial}{\partial t}|\psi\rangle = \hat H|\psi\rangle\end{aligned} \]

The Schrödinger equation: the differential form of the sentence “the Hamiltonian generates time”. A warning: the form \(\hat U(t)=e^{-it\hat H/\hbar}\) is valid if \(\hat H\) does not depend explicitly on time. If the Hamiltonian changes with the clock, each small step has a different generator and a simple exponential does not work.

A sign subtlety: in position \(\hat p=-i\hbar\,\partial_x\), but in the Schrödinger equation \(\hat H\leftrightarrow+i\hbar\,\partial_t\). The reason is in the definitions. In translation \(\psi(x)\to\psi(x-a)\), so we look for the old value behind us. In time \(\psi(t)\to\psi(t+\delta t)\), we want the future. The signs of the derivatives come out opposite so that the exponential pattern stays \(e^{-i\,\cdot/\hbar}\) in both.

Board 7544369

The symmetry test: \([\hat H,\hat G]=0\)

This board is locked for now. To open it, first finish the questions of this board: .

In one sentenceIf a transformation does not change the Hamiltonian, \(\hat U^\dagger\hat H\hat U=\hat H\), it is a symmetry of the system. At small ε this condition reduces to a single commutator: \([\hat H,\hat G]=0\). This is how you check a symmetry in a system.

The continuation of the sentence on Board 6. A \(\hat U(\varepsilon)\), generated by a Hermitian \(\hat G\), is a symmetry of the physical system if it satisfies this condition:

\[ \hat U^\dagger(\varepsilon)\,\hat H\,\hat U(\varepsilon)=\hat H \]

The Hamiltonian stays as it is under the transformation (“does not change, remains as it is under the action of \(\hat U(\varepsilon)\)”). Why do we look at \(\hat H\)? All the physics of the system is in it: both the energy levels and the time evolution come from it. To see why the pattern is \(\hat U^\dagger\hat H\hat U\), transform a state and look at the expectation value of the energy:

\[ \langle\hat U\psi|\,\hat H\,|\hat U\psi\rangle=\langle\psi|\,\hat U^\dagger\hat H\hat U\,|\psi\rangle=\langle\psi|\,\hat H\,|\psi\rangle \]
\[ \begin{aligned}&\langle\hat U\psi|\,\hat H\,|\hat U\psi\rangle \\[2pt] &\quad = \langle\psi|\,\hat U^\dagger\hat H\hat U\,|\psi\rangle \\[2pt] &\quad = \langle\psi|\,\hat H\,|\psi\rangle\end{aligned} \]

If the condition holds, every state and its transformed version give the same energy statistics; whether you shift or rotate the system, the physics looks the same. We will return to this pattern of “wrapping an operator with \(\hat U^\dagger\cdots\hat U\)” on Board 11, under passive transformations.

An equivalent form: multiply both sides from the left by \(\hat U\) and use \(\hat U\hat U^\dagger=\hat I\), which gives \(\hat H\hat U=\hat U\hat H\). A symmetry means the transformation commutes with the Hamiltonian.

Infinitesimal level (HW in red on the board). Instead of checking the condition for every ε, let us look at first order. Write the three factors:

\[ \hat U^\dagger\hat H\hat U=\Big(\hat I+\frac{i}{\hbar}\varepsilon\hat G^\dagger+O(\varepsilon^2)\Big)\,\hat H\,\Big(\hat I-\frac{i}{\hbar}\varepsilon\hat G+O(\varepsilon^2)\Big) \]
\[ \begin{aligned}&\hat U^\dagger\hat H\hat U \\[2pt] &\quad = \Big(\hat I+\frac{i}{\hbar}\varepsilon\hat G^\dagger+O(\varepsilon^2)\Big)\,\hat H\,\Big(\hat I-\frac{i}{\hbar}\varepsilon\hat G+O(\varepsilon^2)\Big)\end{aligned} \]

Multiply from left to right; keep \(\hat H\) in place, because operators generally do not commute:

\[ \hat U^\dagger\hat H\hat U=\hat H-\frac{i}{\hbar}\varepsilon\,\hat H\hat G+\frac{i}{\hbar}\varepsilon\,\hat G^\dagger\hat H+O(\varepsilon^2) \]
\[ \begin{aligned}&\hat U^\dagger\hat H\hat U \\[2pt] &\quad = \hat H-\frac{i}{\hbar}\varepsilon\,\hat H\hat G+\frac{i}{\hbar}\varepsilon\,\hat G^\dagger\hat H+O(\varepsilon^2)\end{aligned} \]

The dropped term is \(\frac{\varepsilon^2}{\hbar^2}\hat G^\dagger\hat H\hat G\). Symmetry wants this to equal \(\hat H\); the \(\hat H\) on the two sides cancel:

\[ 0=\frac{i}{\hbar}\,\varepsilon\,\big(\hat G^\dagger\hat H-\hat H\hat G\big)=\frac{i}{\hbar}\,\varepsilon\,\big(\hat G\hat H-\hat H\hat G\big)\quad\Longrightarrow\quad\boxed{[\hat H,\hat G]=0} \]
\[ \begin{aligned}&0 = \frac{i}{\hbar}\,\varepsilon\,\big(\hat G^\dagger\hat H-\hat H\hat G\big) \\[2pt] &\quad = \frac{i}{\hbar}\,\varepsilon\,\big(\hat G\hat H-\hat H\hat G\big) \\[2pt] &\quad \Longrightarrow \boxed{[\hat H,\hat G]=0}\end{aligned} \]

The middle step used \(\hat G^\dagger=\hat G\) (the red “Ĝ Hermitian” notes on the board; we proved it on Board 5). The boxed result is the most important line of this week, and the starred note agrees: “This is how you check sym. in a phys. sys.” Instead of dealing with the whole family of transformations, you compute a single commutator.

Is checking the small transformation enough? Yes. If \([\hat H,\hat G]=0\), then \(\hat H\), \(\hat G\) commutes with every power, and so with the whole series of \(e^{-i\varepsilon\hat G/\hbar}\). Large transformations are symmetries too.

Computing the commutator takes the homework formula on Board 13: \([V(\hat x),\hat p]=i\hbar\,V'(\hat x)\). The kinetic term \(\hat p^2/2m\), always commutes with \(\hat p\). So for \(\hat H=\hat p^2/2m+V(\hat x)\), \([\hat H,\hat p]=i\hbar\,V'(\hat x)\); translation symmetry is exactly “V' is zero everywhere”, that is, the potential is the same everywhere.

High school example

If you rotate a square by 90° you get the same square; by 30° you do not. A circle is the same at every angle. In high school you call this rotational symmetry, and to check it you rotate the shape and lay it over the old one. In quantum mechanics the Hamiltonian takes the place of the shape, and the “rotate and overlay” operation is \(\hat U^\dagger\hat H\hat U=\hat H\). For something symmetric at every angle like a circle you need not try the angles one by one: if it does not change under a very small rotation, it does not change under any. The commutator test is exactly that “very small rotation” trial.

2. Write \(\hat U\approx\hat I-\frac{i\varepsilon}{\hbar}\hat G\), \(\hat U^\dagger\approx\hat I+\frac{i\varepsilon}{\hbar}\hat G^\dagger\).

4. Set it equal to \(\hat H\) and put in \(\hat G^\dagger=\hat G\): \([\hat G,\hat H]=0\), that is, \([\hat H,\hat G]=0\).

5. For full marks show the converse: if \([\hat H,\hat G]=0\), it is a symmetry for every ε. Define \(\hat F(\varepsilon)=\hat U^\dagger\hat H\hat U\). \(\frac{d\hat F}{d\varepsilon}=\frac{i}{\hbar}\hat U^\dagger\big(\hat G\hat H-\hat H\hat G\big)\hat U=0\), and \(\hat F(0)=\hat H\). A function with zero derivative is constant: \(\hat F(\varepsilon)=\hat H\).

A common mistake: taking \(\hat H\hat G\) and \(\hat G\hat H\) to be the same when multiplying. Then the first order terms always cancel and nothing is proved.

Board 8

Heisenberg: operators change in time too

This board is locked for now. To open it, first finish the questions of this board: .

In one sentenceThe time change of an operator with no t in its formula is set by its commutator with the Hamiltonian: \(\frac{d\hat A}{dt}=\frac{i}{\hbar}[\hat H,\hat A]\). The same for expectation values: \(\frac{d\langle\hat A\rangle}{dt}=\frac{i}{\hbar}\big\langle[\hat H,\hat A]\big\rangle\).

To go from symmetry to conservation one piece is missing: the equation that tells how a quantity changes in time. The lecturer first reminded us of what we know. A ket or wave function changes by the Schrödinger equation:

\[ i\hbar\,\frac{\partial}{\partial t}\psi(t,x)=\hat H\,\psi(t,x) \]

Then the same question was asked for an operator. The answer is the Heisenberg equation; but first the word in quotes on the board, “explicitly”.

Explicit time dependence. If an operator depends explicitly on time, t appears in its formula. \(\hat x\), neither \(\hat p\) nor \(\hat H=\hat p^2/2m+V(\hat x)\) contains t: \(\partial\hat A/\partial t=0\). But the particle moves and \(\langle x\rangle\) changes. The change comes from the state, not from the formula of the operator. An explicitly time-dependent example: a charge in an oscillating electric field, \(\hat H(t)=\hat p^2/2m+qE_0\,\hat x\cos\omega t\).

The last line of the board, for an \(\hat A\) with \(\partial\hat A/\partial t=0\):

\[ \frac{d\hat A}{dt}=\frac{i}{\hbar}\,[\hat H,\hat A] \]

Derivation from the expectation value. In \(\langle\hat A\rangle=\langle\psi|\hat A|\psi\rangle\) the ket and bra change in time:

\[ \frac{d}{dt}\langle\psi|\hat A|\psi\rangle=\Big(\frac{d}{dt}\langle\psi|\Big)\hat A|\psi\rangle+\langle\psi|\hat A\Big(\frac{d}{dt}|\psi\rangle\Big) \]
\[ \begin{aligned}&\frac{d}{dt}\langle\psi|\hat A|\psi\rangle \\[2pt] &\quad = \Big(\frac{d}{dt}\langle\psi|\Big)\hat A|\psi\rangle+\langle\psi|\hat A\Big(\frac{d}{dt}|\psi\rangle\Big)\end{aligned} \]

From the Schrödinger equation \(\frac{d}{dt}|\psi\rangle=-\frac{i}{\hbar}\hat H|\psi\rangle\). On the bra side take the adjoint: \(\hat H^\dagger=\hat H\) and \((-i)^*=+i\), so \(\frac{d}{dt}\langle\psi|=+\frac{i}{\hbar}\langle\psi|\hat H\). Substitute:

\[ \frac{d\langle\hat A\rangle}{dt}=\frac{i}{\hbar}\langle\psi|\hat H\hat A|\psi\rangle-\frac{i}{\hbar}\langle\psi|\hat A\hat H|\psi\rangle=\frac{i}{\hbar}\big\langle[\hat H,\hat A]\big\rangle \]
\[ \begin{aligned}&\frac{d\langle\hat A\rangle}{dt} \\[2pt] &\quad = \frac{i}{\hbar}\langle\psi|\hat H\hat A|\psi\rangle-\frac{i}{\hbar}\langle\psi|\hat A\hat H|\psi\rangle \\[2pt] &\quad = \frac{i}{\hbar}\big\langle[\hat H,\hat A]\big\rangle\end{aligned} \]

Operator form. The \(d\hat A/dt\), on the board is the derivative of the operator in the Heisenberg picture. In this picture the state is held fixed and time evolution is put on the operator (the passive pattern of Board 11): \(\hat A(t)=\hat U^\dagger(t)\,\hat A\,\hat U(t)\), \(\hat U(t)=e^{-it\hat H/\hbar}\). With \(\frac{d\hat U}{dt}=-\frac{i}{\hbar}\hat H\hat U\) and \(\frac{d\hat U^\dagger}{dt}=\frac{i}{\hbar}\hat U^\dagger\hat H\):

\[ \frac{d\hat A(t)}{dt}=\frac{i}{\hbar}\,\hat U^\dagger\hat H\hat A\,\hat U-\frac{i}{\hbar}\,\hat U^\dagger\hat A\hat H\,\hat U=\frac{i}{\hbar}\,\hat U^\dagger[\hat H,\hat A]\,\hat U=\frac{i}{\hbar}\,[\hat H,\hat A(t)] \]
\[ \begin{aligned}&\frac{d\hat A(t)}{dt} \\[2pt] &\quad = \frac{i}{\hbar}\,\hat U^\dagger\hat H\hat A\,\hat U-\frac{i}{\hbar}\,\hat U^\dagger\hat A\hat H\,\hat U \\[2pt] &\quad = \frac{i}{\hbar}\,\hat U^\dagger[\hat H,\hat A]\,\hat U \\[2pt] &\quad = \frac{i}{\hbar}\,[\hat H,\hat A(t)]\end{aligned} \]

The last equality used that \(\hat H\) commutes with its own exponential \(\hat U\). If an operator depends explicitly on time, one more term is added on the right: \(\frac{d\hat A}{dt}=\frac{i}{\hbar}[\hat H,\hat A]+\frac{\partial\hat A}{\partial t}\). On the board \(\partial\hat A/\partial t=0\) is assumed, so that term is absent.

Check the place of ħ with units: the unit of \([\hat H,\hat A]\) is J × [A]; dividing by J·s gives [A]/s, “the change of A per second”. If you multiplied by ħ the units would not work. In the lecture recording the lecturer also briefly wrote ħ in the wrong place and corrected it with “ħ should be downstairs”.

Two examples. For \(\hat H=\hat p^2/2m+V(\hat x)\), \([\hat H,\hat x]=-i\hbar\,\hat p/m\) and \([\hat H,\hat p]=i\hbar\,V'(\hat x)\) (these come from the rules on Boards 12–13). Put them into the Heisenberg equation:

\[ \frac{d\langle\hat x\rangle}{dt}=\frac{\langle\hat p\rangle}{m},\qquad \frac{d\langle\hat p\rangle}{dt}=-\big\langle V'(\hat x)\big\rangle \]
\[ \begin{aligned}&\frac{d\langle\hat x\rangle}{dt} = \frac{\langle\hat p\rangle}{m}, \\[2pt] &\frac{d\langle\hat p\rangle}{dt} = -\big\langle V'(\hat x)\big\rangle\end{aligned} \]

The classical \(v=p/m\) and \(F=-dV/dx\): Ehrenfest's theorem. Expectation values obey Newton. The next board asks what happens when the commutator on the right is zero.

High school example

You are driving on a mountain road. The height on the map, \(h(x)\), has no clock in it: \(\partial h/\partial t=0\). But because you are moving, the height where you are changes, \(dh/dt=h'(x)\,v\). The change comes from your motion, not from the map. A tidal shore would be explicit time dependence: even at the same point the water level changes with the clock, \(h(x,t)\). In the Heisenberg equation the commutator term is “the motion of the car” and the \(\partial\hat A/\partial t\) term is “the tide”.

Board 9392183

If there is a symmetry, something is conserved

This board is locked for now. To open it, first finish the questions of this board: .

In one sentencePut \(\hat A=\hat G\) into the Heisenberg equation: since a symmetry gives \([\hat H,\hat G]=0\), \(d\hat G/dt=0\). The generator of a symmetry is conserved: translation → momentum, rotation → angular momentum, time → energy.

The pieces are ready. In the equation of Board 8 put the generator of the symmetry in place of \(\hat A\) (“Let \(\hat A=\hat G\) and \([\hat H,\hat G]=0\)”):

\[ \frac{d\hat G}{dt}=\frac{i}{\hbar}\underbrace{[\hat H,\hat G]}_{\text{symmetry: }0}=0\quad\Longrightarrow\quad\hat G\text{ constant in time} \]
\[ \begin{aligned}&\frac{d\hat G}{dt} = \frac{i}{\hbar}\underbrace{[\hat H,\hat G]}_{\text{symmetry: }0} = 0 \\[2pt] &\quad \Longrightarrow \hat G\text{ constant in time}\end{aligned} \]

The same commutator does two jobs at once. On Board 7 it was the symmetry test; here it is the conservation test. This is the quantum version of Noether's theorem in classical mechanics: every continuous symmetry brings a conservation law. Classically the theorem is proved with the action principle; in quantum mechanics it is a two-line commutator calculation.

What does it mean in the language of measurement? The first result on the board is that the expectation value is constant: \(\langle\psi|\hat G|\psi\rangle=\langle\hat G\rangle\) stays the same in time. Actually more is true: in a measurement of \(\hat G\), the probability of each result is constant. \(\hat U(t)\), since it commutes with \(\hat G\), it also commutes with the projections of \(\hat G\):

\[ P(g_n,t)=\langle\psi(t)|\hat P_n|\psi(t)\rangle=\langle\psi(0)|\hat U^\dagger\hat P_n\hat U|\psi(0)\rangle=\langle\psi(0)|\hat P_n|\psi(0)\rangle=P(g_n,0) \]
\[ \begin{aligned}&P(g_n,t) \\[2pt] &\quad = \langle\psi(t)|\hat P_n|\psi(t)\rangle \\[2pt] &\quad = \langle\psi(0)|\hat U^\dagger\hat P_n\hat U|\psi(0)\rangle \\[2pt] &\quad = \langle\psi(0)|\hat P_n|\psi(0)\rangle \\[2pt] &\quad = P(g_n,0)\end{aligned} \]

The eigenstate sentence in the middle of the board is a special case of this. If the system starts in an eigenstate of \(\hat G\), \(\hat G|g_n\rangle=g_n|g_n\rangle\), time evolution cannot take it out of this eigenvalue:

\[ \hat G\,\big(\hat U(t)|g_n\rangle\big)=\hat U(t)\,\hat G|g_n\rangle=g_n\,\big(\hat U(t)|g_n\rangle\big) \]
\[ \begin{aligned}&\hat G\,\big(\hat U(t)|g_n\rangle\big) \\[2pt] &\quad = \hat U(t)\,\hat G|g_n\rangle \\[2pt] &\quad = g_n\,\big(\hat U(t)|g_n\rangle\big)\end{aligned} \]

The evolved state is still an eigenstate with eigenvalue \(g_n\). Whenever you measure, you will certainly find \(g_n\).

Board note

The board says “if the system is in \(|g_n\rangle\), it stays in the same state in time”. What is certain is this: it stays among the states belonging to the same eigenvalue \(g_n\). If \(g_n\) is nondegenerate (a single state for that eigenvalue) the state really stays the same, up to a phase factor; then \(|g_n\rangle\) must also be an energy eigenstate. If it is degenerate, the state can change within that eigenspace. Example: in hydrogen \((|1s\rangle+|2s\rangle)/\sqrt2\). Both parts have \(L_z=0\); but their energies differ, their phases rotate at different speeds and the state changes in time. The only thing that does not change is that a measurement of \(L_z\) gives 0 at every moment.

Instead of memorizing both, remember one rule. An operator is determined by its eigenbasis, \(\hat A=\sum_na_n|a_n\rangle\langle a_n|\). If you turn the basis with \(\hat V\), the operator turns too:

\[ \sum_n a_n\,\big(\hat V|a_n\rangle\big)\big(\langle a_n|\hat V^\dagger\big)=\hat V\hat A\,\hat V^\dagger \]
\[ \begin{aligned}&\sum_n a_n\,\big(\hat V|a_n\rangle\big)\big(\langle a_n|\hat V^\dagger\big) \\[2pt] &\quad = \hat V\hat A\,\hat V^\dagger\end{aligned} \]

Active: the basis turns together with the state by \(\hat U\), \(\hat V=\hat U\), with result \(\hat U\hat A\hat U^\dagger\). This is the operator you measure when you also turn the measuring device together with the state. When everything turns together nothing should change, and indeed:

\[ \langle\psi'|\hat A'_{\text{active}}|\psi'\rangle=\langle\psi|\hat U^\dagger\,\hat U\hat A\hat U^\dagger\,\hat U|\psi\rangle=\langle\psi|\hat A|\psi\rangle \]
\[ \begin{aligned}&\langle\psi'|\hat A'_{\text{active}}|\psi'\rangle \\[2pt] &\quad = \langle\psi|\hat U^\dagger\,\hat U\hat A\hat U^\dagger\,\hat U|\psi\rangle \\[2pt] &\quad = \langle\psi|\hat A|\psi\rangle\end{aligned} \]

Passive: the basis turns the opposite way, \(\hat V=\hat U^\dagger\), with result \(\hat U^\dagger\hat A\hat U\). Since the state does not change at all, the whole effect is put on the operator, and it gives the same number as the active transformation:

\[ \langle\psi|\hat A'_{\text{passive}}|\psi\rangle=\langle\psi|\hat U^\dagger\hat A\hat U|\psi\rangle=\langle\hat U\psi|\hat A|\hat U\psi\rangle=\langle\psi'|\hat A|\psi'\rangle \]
\[ \begin{aligned}&\langle\psi|\hat A'_{\text{passive}}|\psi\rangle \\[2pt] &\quad = \langle\psi|\hat U^\dagger\hat A\hat U|\psi\rangle \\[2pt] &\quad = \langle\hat U\psi|\hat A|\hat U\psi\rangle = \langle\psi'|\hat A|\psi'\rangle\end{aligned} \]

Everything we see in an experiment is such numbers; the two views are physically equivalent. A concrete example is translation, \(\hat U=\hat T(a)\):

\[ \hat T^\dagger\,\hat x\,\hat T=\hat x+a,\qquad \hat T\,\hat x\,\hat T^\dagger=\hat x-a \]
\[ \begin{aligned}&\hat T^\dagger\,\hat x\,\hat T = \hat x+a, \\[2pt] &\hat T\,\hat x\,\hat T^\dagger = \hat x-a\end{aligned} \]

The proof with a test function: in \(\hat T^\dagger\hat x\hat T\psi\) first shift the packet to the right by a, \(\psi(x-a)\); multiply by x, \(x\,\psi(x-a)\); then shift back (x + a in place of x): \((x+a)\,\psi(x)\). The first is passive: in the same state \(\langle\hat x+a\rangle=\langle x\rangle+a\), the position of the packet shifted right by a. The second is the active operator: if you shift the ruler to the right by a along with the packet, the reading is \(x-a\) and the shifted packet again gives \(\langle x\rangle\).

We already used these two patterns twice this week. The symmetry condition \(\hat U^\dagger\hat H\hat U=\hat H\) on Board 7 is the passive pattern: we transformed the Hamiltonian and checked whether it stayed the same. The Heisenberg picture \(\hat A(t)=\hat U^\dagger(t)\hat A\hat U(t)\) on Board 8 is also the passive pattern, for time. In the Schrödinger picture the state changes and the operator is fixed (active); in the Heisenberg picture the state is fixed and the operator changes (passive).

Books can be confusing here: some sources give \(\hat U^\dagger\hat A\hat U\) alone as “the transformed operator”. Always settle which is meant with this question: am I changing the state or the basis? To check the sign use the translation example: \(\hat T^\dagger\hat x\hat T=\hat x+a\).

You are sitting on a train at a station, with another train on the next track. Looking out the window you wonder “is it us moving or them?”; all you see is the relative motion. The three rules of the commutator

This board is locked for now. To open it, first finish the questions of this board: .

In one sentenceThe commutator distributes over addition; on a product it behaves like the product rule of the derivative, but the factor it does not touch keeps its place: \([\hat A\hat B,\hat C]=\hat A[\hat B,\hat C]+[\hat A,\hat C]\hat B\) and \([\hat A,\hat B\hat C]=[\hat A,\hat B]\hat C+\hat B[\hat A,\hat C]\).

The definition is at the bottom of Board 11: \([\hat A,\hat B]\equiv\hat A\hat B-\hat B\hat A\). Numbers commute, \(3\cdot5=5\cdot3\); operators and matrices generally do not. The commutator is a measure of this difference. What follows immediately from the definition:

\[ [\hat A,\hat A]=0,\qquad [\hat B,\hat A]=-[\hat A,\hat B],\qquad [\hat A,c\,\hat B]=c\,[\hat A,\hat B],\qquad [\hat A,c]=0 \]
\[ \begin{aligned}&[\hat A,\hat A] = 0, \\[2pt] &[\hat B,\hat A] = -[\hat A,\hat B], \\[2pt] &[\hat A,c\,\hat B] = c\,[\hat A,\hat B], \\[2pt] &[\hat A,c] = 0\end{aligned} \]

The three commutator identities on the board will come in the exam, directly or inside a proof. You should be able to prove all three by expanding the definition.

Rule 1, sum. Expand the definition and group the terms:

\[ [\hat A+\hat B,\hat C]=\hat A\hat C+\hat B\hat C-\hat C\hat A-\hat C\hat B=[\hat A,\hat C]+[\hat B,\hat C] \]
\[ \begin{aligned}&[\hat A+\hat B,\hat C] = \hat A\hat C+\hat B\hat C-\hat C\hat A-\hat C\hat B \\[2pt] &\quad = [\hat A,\hat C]+[\hat B,\hat C]\end{aligned} \]

Rule 2, product on the left. The red arrows on the board are the proof itself. Expand the right side and add:

\[ \hat A[\hat B,\hat C]+[\hat A,\hat C]\hat B=\hat A\hat B\hat C-\hat A\hat C\hat B+\hat A\hat C\hat B-\hat C\hat A\hat B=\hat A\hat B\hat C-\hat C\hat A\hat B=[\hat A\hat B,\hat C] \]
\[ \begin{aligned}&\hat A[\hat B,\hat C]+[\hat A,\hat C]\hat B \\[2pt] &\quad = \hat A\hat B\hat C-\hat A\hat C\hat B+\hat A\hat C\hat B-\hat C\hat A\hat B \\[2pt] &\quad = \hat A\hat B\hat C-\hat C\hat A\hat B = [\hat A\hat B,\hat C]\end{aligned} \]

The two middle \(\hat A\hat C\hat B\) terms come with opposite signs and cancel; these are the ones crossed out in red on the board. What remains is the definition itself. The trick is adding and subtracting \(\hat A\hat C\hat B\), and grouping the first two as \(\hat A[\,\cdot\,]\), and the last two as \([\,\cdot\,]\hat B\).

Rule 3, product on the right. The same calculation, or rule 2 plus antisymmetry:

\[ [\hat A,\hat B\hat C]=-[\hat B\hat C,\hat A]=-\hat B[\hat C,\hat A]-[\hat B,\hat A]\hat C=[\hat A,\hat B]\hat C+\hat B[\hat A,\hat C] \]
\[ \begin{aligned}&[\hat A,\hat B\hat C] = -[\hat B\hat C,\hat A] \\[2pt] &\quad = -\hat B[\hat C,\hat A]-[\hat B,\hat A]\hat C \\[2pt] &\quad = [\hat A,\hat B]\hat C+\hat B[\hat A,\hat C]\end{aligned} \]

The easy way to memorize it is the product rule of the derivative, \((uv)'=u'v+uv'\): the commutator touches each factor once in turn. The difference is that the factor it does not touch stays on its side. In rule 2, \(\hat A\) is on the left and \(\hat B\) on the right; in rule 3, \(\hat C\) is on the right and \(\hat B\) on the left. A common mistake is putting \(\hat A\) on the wrong side: \(\hat A[\hat B,\hat C]\) and \([\hat B,\hat C]\hat A\) are generally different.

The last line of the board prepares for the next: the canonical operators \(\hat x\) and \(\hat p\), \([\hat x,\hat p]=i\hbar\). A check with a test function in the position representation:

\[ [\hat x,\hat p]\,f=x\big(-i\hbar f'\big)-\big(-i\hbar\big)\big(x f\big)'=-i\hbar\,xf'+i\hbar\,\big(f+xf'\big)=i\hbar\,f \]
\[ \begin{aligned}&[\hat x,\hat p]\,f \\[2pt] &\quad = x\big(-i\hbar f'\big)-\big(-i\hbar\big)\big(x f\big)' \\[2pt] &\quad = -i\hbar\,xf'+i\hbar\,\big(f+xf'\big) = i\hbar\,f\end{aligned} \]

The product rule \((xf)'=f+xf'\) is the heart of the matter here too. Two examples, with rules 2 and 3: \([\hat x,\hat p^2]=[\hat x,\hat p]\hat p+\hat p[\hat x,\hat p]=2i\hbar\,\hat p\) and \([\hat x^2,\hat p]=\hat x[\hat x,\hat p]+[\hat x,\hat p]\hat x=2i\hbar\,\hat x\).

Pauli matrices are a good laboratory for trying this with concrete matrices; they are the basic operators of qubits:

\[ \sigma_x=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad \sigma_y=\begin{pmatrix}0&-i\\i&0\end{pmatrix},\quad \sigma_z=\begin{pmatrix}1&0\\0&-1\end{pmatrix} \]
\[ \begin{aligned}&\sigma_x = \begin{pmatrix}0&1\\1&0\end{pmatrix}, \\[2pt] &\sigma_y = \begin{pmatrix}0&-i\\i&0\end{pmatrix}, \\[2pt] &\sigma_z = \begin{pmatrix}1&0\\0&-1\end{pmatrix}\end{aligned} \]

\([\hat x,\hat p^n]\) by induction, and as homework \([f(\hat x),\hat p]\)

In one sentence\([\hat x,\hat p^n]=i\hbar\,n\,\hat p^{\,n-1}\): taking the commutator with \(\hat x\) is like applying \(i\hbar\,d/dp\) to a power of \(\hat p\). The same in the other direction: \([f(\hat x),\hat p]=i\hbar\,f'(\hat x)\). The first was proved by induction, the second is homework.

Two results from the rules on Board 12 and \([\hat x,\hat p]=i\hbar\). The first:

\[ [\hat x,\hat p^n]=i\hbar\,n\,\hat p^{\,n-1} \]

The derivative of \(p^n\) resembles \(np^{n-1}\); this is no coincidence. In the momentum representation \(\hat x=i\hbar\,\partial_p\) (Board 2), and \([i\hbar\,\partial_p,\,p^n]\) is exactly \(i\hbar\,n\,p^{n-1}\).

Proof: mathematical induction. Like dominoes: show that the first tile falls, then show that every tile knocks over the next.

Base case. n = 1 is the given relation, \([\hat x,\hat p]=i\hbar\). The board starts from n = 2, using rule 3 with \(\hat B=\hat C=\hat p\):

\[ [\hat x,\hat p^2]=[\hat x,\hat p]\,\hat p+\hat p\,[\hat x,\hat p]=i\hbar\,\hat p+i\hbar\,\hat p=2i\hbar\,\hat p \]
\[ \begin{aligned}&[\hat x,\hat p^2] = [\hat x,\hat p]\,\hat p+\hat p\,[\hat x,\hat p] \\[2pt] &\quad = i\hbar\,\hat p+i\hbar\,\hat p = 2i\hbar\,\hat p\end{aligned} \]

For n = 2 the formula says \(2i\hbar\,\hat p^{\,1}\); it holds.

Induction step. Assume it is true for n − 1 (the red box on the board, “if (n−1) order holds”):

\[ [\hat x,\hat p^{\,n-1}]=i\hbar\,(n-1)\,\hat p^{\,n-2} \]

Write \(\hat p^n\) as \(\hat p\cdot\hat p^{\,n-1}\) and apply rule 3 with \(\hat B=\hat p\), \(\hat C=\hat p^{\,n-1}\):

\[ [\hat x,\hat p^n]=[\hat x,\hat p\,\hat p^{\,n-1}]=[\hat x,\hat p]\,\hat p^{\,n-1}+\hat p\,\underbrace{[\hat x,\hat p^{\,n-1}]}_{\text{assumption}}=i\hbar\,\hat p^{\,n-1}+\hat p\;i\hbar\,(n-1)\,\hat p^{\,n-2}=i\hbar\,n\,\hat p^{\,n-1} \]
\[ \begin{aligned}&[\hat x,\hat p^n] = [\hat x,\hat p\,\hat p^{\,n-1}] \\[2pt] &\quad = [\hat x,\hat p]\,\hat p^{\,n-1}+\hat p\,\underbrace{[\hat x,\hat p^{\,n-1}]}_{\text{assumption}} \\[2pt] &\quad = i\hbar\,\hat p^{\,n-1}+\hat p\;i\hbar\,(n-1)\,\hat p^{\,n-2} \\[2pt] &\quad = i\hbar\,n\,\hat p^{\,n-1}\end{aligned} \]

In the last step \(\hat p\,\hat p^{\,n-2}=\hat p^{\,n-1}\) and \(1+(n-1)=n\). This is allowed because \(\hat p\) commutes with its own powers; you could not combine a term containing \(\hat x\) this way. If we can go from n − 1 to n and n = 2 is true, then 3, 4, 5, … are all true. The red note on the right of the board: “nth order results can be proved”.

Homework (HW): \([f(\hat x),\hat p]=i\hbar\,\dfrac{df}{dx}(\hat x)\). It was left unproved on the board. Since the lecturer said the exam will resemble the homework, I write both routes; you should be able to do both with the book closed.

Route 1: powers and induction. First do the same induction on the x side, this time with rule 2:

\[ [\hat x^n,\hat p]=[\hat x\,\hat x^{\,n-1},\hat p]=\hat x\,[\hat x^{\,n-1},\hat p]+[\hat x,\hat p]\,\hat x^{\,n-1}=\hat x\;i\hbar(n-1)\hat x^{\,n-2}+i\hbar\,\hat x^{\,n-1}=i\hbar\,n\,\hat x^{\,n-1} \]
\[ \begin{aligned}&[\hat x^n,\hat p] = [\hat x\,\hat x^{\,n-1},\hat p] \\[2pt] &\quad = \hat x\,[\hat x^{\,n-1},\hat p]+[\hat x,\hat p]\,\hat x^{\,n-1} \\[2pt] &\quad = \hat x\;i\hbar(n-1)\hat x^{\,n-2}+i\hbar\,\hat x^{\,n-1} \\[2pt] &\quad = i\hbar\,n\,\hat x^{\,n-1}\end{aligned} \]

Then expand f in a power series, \(f(x)=\sum_nc_nx^n\), and apply term by term with rule 1 (the commutator distributes over addition):

\[ [f(\hat x),\hat p]=\sum_nc_n\,[\hat x^n,\hat p]=i\hbar\sum_nc_n\,n\,\hat x^{\,n-1}=i\hbar\,f'(\hat x) \]
\[ \begin{aligned}&[f(\hat x),\hat p] = \sum_nc_n\,[\hat x^n,\hat p] \\[2pt] &\quad = i\hbar\sum_nc_n\,n\,\hat x^{\,n-1} = i\hbar\,f'(\hat x)\end{aligned} \]

Route 2: position representation and a test function. An operator equality means doing the same thing to every function. Take an arbitrary g(x) and apply both sides to it:

\[ [f(\hat x),\hat p]\,g=f\big(-i\hbar\,g'\big)-\big(-i\hbar\big)\big(fg\big)'=-i\hbar\,fg'+i\hbar\,\big(f'g+fg'\big)=i\hbar\,f'\,g \]
\[ \begin{aligned}&[f(\hat x),\hat p]\,g \\[2pt] &\quad = f\big(-i\hbar\,g'\big)-\big(-i\hbar\big)\big(fg\big)' \\[2pt] &\quad = -i\hbar\,fg'+i\hbar\,\big(f'g+fg'\big) \\[2pt] &\quad = i\hbar\,f'\,g\end{aligned} \]

It is true for every g, so \([f(\hat x),\hat p]=i\hbar f'(\hat x)\). If you try to do it without writing g, you will miss the \(f'g\) term in \((fg)'\) and wrongly find zero; that is why the test function is essential.

This formula is the engine of this week's calculations. For \(\hat H=\hat p^2/2m+V(\hat x)\), \([\hat H,\hat p]=[V(\hat x),\hat p]=i\hbar\,V'(\hat x)\): the symmetry table on Board 7 and the Ehrenfest result \(d\langle p\rangle/dt=-\langle V'\rangle\) on Board 8 come from here. The mirror formula goes the same way: \([\hat x,g(\hat p)]=i\hbar\,g'(\hat p)\).

High school example

The high school induction example \(1+2+\dots+n=\frac{n(n+1)}{2}\). At n = 1, 1 = 1, true. If it is true for n − 1, add n: \(\frac{(n-1)n}{2}+n=\frac{n(n+1)}{2}\), true again. The proof on the board has the same skeleton: base case, assumption, one step forward. The only thing that changes is the tool for taking the step; there addition, here the product rule of the commutator.

Exam pattern: the skeleton of an induction proof

1. Write the claim: \(P(n):\;[\hat x,\hat p^n]=i\hbar n\hat p^{\,n-1}\).

2. Base case: \(P(1)\) is the given relation. If you like, also show \(P(2)\) with rule 3 (as on the board).

3. Assumption: let \(P(n-1)\) be true. Write this explicitly; part of the marks is in this sentence.

4. Step: \(\hat p^n=\hat p\,\hat p^{\,n-1}\), apply rule 3, substitute the assumption, add.

5. Concluding sentence: \(P(n-1)\Rightarrow P(n)\) and \(P(1)\) are true, so it holds for every n ≥ 1.

The same skeleton works for \([\hat x^n,\hat p]\) and \([\hat x,\hat p^n]\); the only difference is which product rule (2 or 3) you use.
